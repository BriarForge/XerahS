- COMPCAT-004: every importer returns a report of fields/records retained, transformed, defaulted, quarantined, rejected and ignored; silent data loss prohibited; unsupported critical behavior blocks acceptance. Define the quarantine representation (kept inert, never applied, reported) and test.
- COMPCAT-006: exports (whatever exists: XANN save, SXCU/destination export if any, preferences) use an explicit version and target, write atomically, avoid machine-specific handles, omit or substitute secrets, and identify non-portable omissions in the result. If there is no export surface for a format, say so; don't invent product features beyond a minimal export result report.
- COMPCAT-015: an adversarial matrix per reader: malformed, deeply nested (depth bound), oversized (byte/element bounds), cyclic (if references exist), compressed bombs (gzip XANN ratio/size bound), duplicate keys, invalid UTF-8, path traversal in any embedded path. Each rejected safely with a stable code, bounded memory/time, no network, no local data in diagnostics.
- COMPCAT-016: write down canonical rules (UTC ISO-8601 times with ms, '.' decimals, case rules for IDs/enums, '/' path separators or portable paths, LF newlines, NFC Unicode) in a short doc next to the readers, with fixtures that load identically under different locales and newline/Unicode-normalization variants.
