# Schemas

Machine-readable structural schemas for the Product Contract:

- `manifest.schema.json` defines the capability manifest required by D-CON-001.
- `parity-ledger.schema.json` defines the common row shape and platform
  dispositions for the five BXIP001 parity ledgers.
- `backlog.schema.json` defines the progressive completion waves, owned work
  packages, dependency graph, and parity-row routing rules.
- `approval-record.schema.json` defines durable human product-owner decisions,
  their exact package scope, effects, and gates that remain after approval.

Capability-specific configuration, history, workflow, uploader, annotation,
and protocol schemas belong with their capability package or shared domain.
